# 🚕 Taxi Trip Distance Analysis in Armenia

### Statistical Analysis | One-Sample T-Test | Data Analytics

## 📌 Project Overview

This project investigates whether the average distance of a taxi trip in Armenia differs significantly from the claimed value of **14.4 km**.

The analysis uses a sample of taxi trip observations and applies statistical methods to evaluate the claim.

The main objective is to understand whether the sample provides sufficient statistical evidence to reject the proposed population mean.

## 🎯 Research Question

**Is the average taxi trip distance in Armenia significantly different from 14.4 km?**

## 🧪 Hypothesis Testing

A two-tailed One-Sample T-Test was selected.

- **Null Hypothesis (H₀):** μ = 14.4 km
- **Alternative Hypothesis (H₁):** μ ≠ 14.4 km

Significance level:

α = 0.05

## 💡 Conclusion

Since the p-value is greater than the significance level (0.05), we fail to reject the null hypothesis.

There is insufficient statistical evidence to conclude that the average taxi trip distance in Armenia is significantly different from 14.4 km.

**Important:** Failing to reject the null hypothesis does not prove that the population mean is exactly 14.4 km.
